# Landway Admin Dashboard - Quick Start Guide

## Getting Started

### Step 1: Access the Dashboard
1. Open your web browser
2. Navigate to `login.html`
3. Use these credentials:
   - **Email:** `admin@landway.com`
   - **Password:** `Admin123456`
4. Click "Sign In"

### Step 2: Dashboard Overview
Once logged in, you'll see:
- **Header:** Shows "Admin Dashboard" and your profile name
- **Sidebar:** Navigation menu with 4 main sections
- **Stats Cards:** Real-time counts of all data
- **Content Area:** Main section for viewing and managing data

### Step 3: Navigation
The sidebar allows you to switch between:
1. **Accounts** - View registered users
2. **Properties** - View property listings
3. **Inquiries** - View customer inquiries
4. **Employees** - View and manage staff

## Quick Tasks

### View All Accounts
1. Click "Accounts" in sidebar
2. Table shows all registered users
3. Click "View" to see full details
4. Click "Delete" to remove an account

### Manage Properties
1. Click "Properties" in sidebar
2. View all property listings with status
3. Click "View" for complete property information
4. Click "Delete" to remove a property

### Check Inquiries
1. Click "Inquiries" in sidebar
2. See all customer contact requests
3. Click "View" to read the full message
4. Click "Delete" to remove an inquiry

### Add Employees
1. Click "Employees" in sidebar
2. Click "Add Employee" button
3. Fill in the form with:
   - First Name
   - Last Name
   - Email
   - Phone
   - Position
   - Employee ID
4. Click "Add Employee"

### Change Your Password
1. Click your name in top-right corner
2. Select "Change Password"
3. Enter current password
4. Enter new password (8+ characters)
5. Confirm new password
6. Click "Change Password"

### Logout
1. Click your name in top-right corner
2. Click "Logout"
3. You'll be redirected to login page

## Important Notes

⚠️ **Security Reminder:**
- Change the default admin password immediately
- Keep your credentials secure
- Don't share login information
- Logout when finished

✅ **Data Tips:**
- All data is stored in your browser (localStorage)
- Clear browser data to reset everything
- Data persists across browser sessions
- Different browsers maintain separate data

📱 **Responsive Design:**
- Dashboard works on all devices
- Use on desktop for best experience
- Mobile-friendly interface available
- Sidebar collapses on small screens

## Statistics Dashboard

The dashboard displays real-time counts:
- 👥 **Total Accounts** - Number of registered users
- 🏠 **Total Properties** - Number of listings
- 📧 **Total Inquiries** - Number of contact submissions
- 👔 **Total Employees** - Number of staff members

## Table Features

Each table includes:
- **Sortable Columns** - Column headers indicate sortable fields
- **Action Buttons** - View, Edit, Delete options
- **Status Badges** - Color-coded status indicators
- **Date Display** - Formatted date information
- **Responsive Layout** - Adjusts for different screen sizes

## Helpful Tips

1. **Empty Tables:** If tables are empty, data hasn't been submitted through forms yet
2. **Confirmation Required:** Delete actions require confirmation to prevent accidents
3. **Modal Details:** Click "View" to see complete information in a popup
4. **Error Messages:** Pay attention to error messages when adding employees
5. **Form Validation:** All required fields must be filled before submission

## Need Help?

- Check that users have registered via `Land Way/register.html`
- Verify properties were added via `add-property.html`
- Confirm inquiries were submitted via `contact.html`
- Use browser DevTools to check localStorage data
- Clear browser cache if data isn't showing
